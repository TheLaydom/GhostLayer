# #BuildHybridAI 2026 submission checklist

Deadline is November 30, 2026 at 2 p.m. Pacific Standard Time, or December 1 at midnight in Bucharest. Eligibility must be confirmed by the entrant against the official rules, including the age-of-majority, residence, and other restrictions. [Official rules](https://firebasehybridaihackathon.devpost.com/rules)

- Verify live Gemini Nano 4 through Firebase AI Logic on desktop Chrome. Use `ONLY_ON_DEVICE` for private classification and keep cloud generation behind the reviewed-text gate. Direct Chrome Prompt API and mock cloud are useful development paths. The Chrome submission requires Nano through Firebase AI Logic.
- Verify a real App Check exchange and live Firebase AI Logic call with synthetic data. The contest accepts debug tokens, and Firebase requires keeping them private. Demonstrate privately and keep the token, production API keys, personal data, and live project secrets out of submission materials and the public repository.
- Publish a functional, open-source GitHub or GitLab repository with source, required assets, license, setup instructions, and actual Firebase calls. Include an English description covering the use of Firebase AI Logic, features, and value. Disclose qualifying pre-existing work as applicable.
- Record a publicly visible YouTube video in English or with English subtitles. Keep it under three minutes and link it from Devpost. [Official rules](https://firebasehybridaihackathon.devpost.com/rules)
